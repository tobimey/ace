# Questions

The format for asking the user to decide in chat. `ace-mode` and every Ace skill that asks in chat use it.

Number each question and give a recommended answer. Write each question in this shape, with a bold title line, then a blank line, then the body, and no markdown fence, heading, or list:

**❓ Q1 - <question title>**

<question body>
A) <choice>
B) <choice>

➡️ <recommended answer>

The body is a few sentences. Put each choice on its own plain line under the body; a question without choices has only the body. The recommended answer is one sentence. Define a specialist term in the same sentence that uses it.
